| Produkt | Co chroni? | Gdzie to "żyje"? | Główny cel |
| :--- | :--- | :--- | :--- |
| **Defender for Office 365** | E-mail, OneDrive, Teams | Microsoft 365 | Ochrona przed phishingiem, złośliwymi linkami i załącznikami. |
| **Defender for Endpoint** | Laptopy, smartfony, serwery | Systemy operacyjne (Win, macOS, Linux) | Wykrywanie wirusów (NGAV) i zaawansowanych ataków (EDR). |
| **Defender for Cloud Apps** | Aplikacje SaaS (nie tylko MS) | Chmura (SaaS) | Monitorowanie Shadow IT i kontrola dostępu do aplikacji chmurowych. |
| **Defender for Cloud** | Serwery, Bazy danych, Kontenery | Azure / AWS / GCP / On-prem | Bezpieczna konfiguracja infrastruktury i ochrona obciążeń (CWPP). |
| **Defender for Identity** | Konta użytkowników i sesje | On-premise Active Directory | Wykrywanie kradzieży poświadczeń i ruchów bocznych (lateral movement). |
| **Microsoft Purview** | Treść plików i bazy danych | M365, Azure, AWS, On-prem | Klasyfikacja danych (etykiety), ochrona przed wyciekiem (DLP) i zgodność (RODO). |
